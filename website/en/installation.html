Installation

iOS

Install iSH

To be able to install CLMMobile on iOS, you will need to install the iSH app. It is a linux emulator that will allow you to run CLMMobile in the background whilst using other apps.

You can get it on the Apple app store.

Get iSH on the App Store

After downloading iSH from the app store, you must enable location services to allow the app to keep running in the background. CLMMobile makes iOS think that it needs your location (whilst it doesn't and doesn't use your location for anything) to keep running in the background with other apps in the foreground.
