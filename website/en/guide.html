Using the timer

Normal mode

To use the timer go to the home page and click on the timer button. You will then be asked to log in. Please enter the user password (using the admin password works too).

After authenticating you will be presented with the timer. It already contains the meeting schedule for today. And will automatically choose between the midweek and weekend schedules.

To start the timer press the blue start button. To stop you press the same button. When stopping the timer you might notice it jumps to the next talk automatically. However it is possible to manually select the current talk. You can do this by clicking the arrows or by clicking on the blue box containing the talk title and selecting the desired talk from there.

Circuit overseer mode

During the visit of the circuit overseer, you can enable circuit overseer mode. This can be accomplished by clicking the blue bottom in the bottom right corner of the screen. It displays the current mode, by clicking it you switch mode to circuit overseer mode. To move back to normal mode, simply click the button again. Operating the timer remains unchanged.

Generating reports

To generate a report of the meeting, go to the home page and click on admin. This may require you to login as admin (if you weren't already logged in as admin). Once logged in you must click on the reports button. This will take you to a view with a list of all meetings. Click on the desired meeting. Now you will see an overview of the recorded times. You can download the pdf report by clicking the blue download button above.

Using the webclock

Using the webclock is very straightforward. You can scan the qr code with a device that is on the same network as the device running CLMMobile, or you can click the webclock button. The webclock displays the remaining time in green and switches to red if the speaker is overtime and will start counting upwards from 0.

Switching language

To change the language of CLMMobile, you must go to the home page and click on admin. This may require you to log in as the admin. Once logged in you will see a language dropdown. Select the desired language and that's it.

Authentication

To authenticate, you must enter either the user or admin password. The default passwords for the user and admin are user and admin respectively. It is obviously recommended to change these.

To change the passwords, you will need to go to the admin page (and log in as the admin). Then at the bottom you will see a change passwords button. Click it, now there should be input fields where you can change the password(s) and submit your changes.
