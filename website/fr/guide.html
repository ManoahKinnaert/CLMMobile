Utilisation du minuteur

Mode normal

Pour utiliser le minuteur, allez sur la page d'accueil et cliquez sur le bouton minuteur. Vous serez alors invité à vous connecter. Entrez le mot de passe utilisateur (le mot de passe admin fonctionne aussi).

Après authentification, vous serez présenté avec le minuteur. Il contient déjà l'horaire des réunions d'aujourd'hui et basculera automatiquement entre les emplois du temps en semaine et le week-end.

Pour démarrer le minuteur, appuyez sur le bouton de démarrage bleu. Pour l'arrêter, appuyez sur le même bouton. En arrêtant le minuteur, vous remarquerez peut-être qu'il passe automatiquement au prochain discours. Cependant, il est possible de sélectionner manuellement le discours en cours. Vous pouvez le faire en cliquant sur les flèches ou en cliquant sur la case bleue contenant le titre du discours, puis en sélectionnant le discours souhaité.

Mode contrôleur de circuit

Pendant la visite du circuit overseur, vous pouvez activer le mode circuit overseur. Cela peut être accompli en cliquant sur le bouton bleu en bas à droite de l'écran. Il affiche le mode en cours ; en cliquant, vous basculez en mode circuit overseur. Pour revenir au mode normal, cliquez simplement sur le bouton à nouveau. Le fonctionnement du minuteur reste inchangé.

Générer un rapport

Pour générer un rapport de la réunion, allez sur la page d'accueil et cliquez sur « admin ». Cela peut nécessiter que vous vous connectiez en tant qu'admin (si vous n'étiez pas déjà connecté en tant qu'admin). Une fois connecté, cliquez sur le bouton « rapports ». Cela vous mènera à une vue récapitulant toutes les réunions. Cliquez sur la réunion souhaitée. Vous verrez alors un aperçu des temps enregistrés. Vous pouvez télécharger le rapport PDF en cliquant sur le bouton de téléchargement bleu ci-dessus.

Utilisation du webclock

L'utilisation du webclock est très simple. Vous pouvez scanner le code QR avec un appareil qui se trouve sur le même réseau que l'appareil exécutant CLMMobile, ou cliquer sur le bouton webclock. Le webclock affiche le temps restant en vert et passe en rouge si l'intervenant est en dépassement de temps, puis commencera à compter à partir de 0.

Changement de langue

Pour changer la langue de CLMMobile, vous devez aller sur la page d'accueil et cliquer sur « admin ». Cela peut nécessiter que vous vous connectiez en tant qu'admin. Une fois connecté, vous verrez une liste déroulante. Sélectionnez la langue souhaitée et c'est tout.

Authentification

Pour vous authentifier, vous devez entrer soit le mot de passe utilisateur, soit le mot de passe admin. Les mots de passe par défaut pour l'utilisateur et l'admin sont respectivement « user » et « admin ». Il est évidemment recommandé de les modifier.

Pour modifier les mots de passe, vous devez aller sur la page admin (et vous connecter en tant qu'admin). En bas, vous verrez un bouton « changer les mots de passe ». Cliquez dessus, des champs de saisie apparaîtront où vous pourrez modifier les mot de passe (s) et soumettre vos modifications.
