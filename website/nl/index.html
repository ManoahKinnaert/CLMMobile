CLMMobile

CLMMobile is een vergadertimer voor gemeentelijke vergaderingen. Het draait als lokale webapplicatie op je apparaat en helpt je de spreekduur tijdens de vergadering bij te houden, zodat het programma op schema blijft. Daarnaast kan het de resterende tijd tijdens een toespraak weergeven.

De app werkt op desktop en mobiel en kan op iOS en iPadOS worden geïnstalleerd via de iSH-app. De app kan vervolgens worden bediend via de browser van elk apparaat in hetzelfde netwerk. Zie de installatie-instructies voor meer informatie.
